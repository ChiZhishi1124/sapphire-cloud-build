# Sapphire cloud build

Personal GitHub Actions builds of the official public [cshariq/Sapphire](https://github.com/cshariq/Sapphire) sources, pinned to `c3766c2881db36aadf93ddfde38c54cb2085b9d4`.

This uses upstream Simplified Chinese localization and the upstream `config/LocalPublic.xcconfig` build configuration. It is not an author-signed Sapphire release. Private camera, microphone, and File Provider implementations are not present in the public source build. The original installed release should be retained until this build has been verified locally.

Only build automation lives in this repository. Source code is fetched directly from the upstream repository by GitHub Actions. No personal files or credentials are included.
